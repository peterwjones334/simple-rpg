# SRPG Deliverables

- **srpg.html** — Interactive viewer with Paper and Neon reading modes. Includes a printable character sheet (use browser Print), core rules summary, and sample adventure.
- **SRPG-Cleaned-Rules.md** — Consolidated, cleaned core rules (also available as PDF/EPUB locally).
- **Sample-Adventure-Black-Fen.md** — One complete sample adventure generated from the List RPG tables.
- Printable character sheet PDF and cleaned-rules PDF/EPUB can be regenerated from the Markdown with pandoc or any Markdown-to-PDF tool.

Open `srpg.html` in a browser for the neon/paper modes and printable sheet.
