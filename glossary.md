# Acronym and Glossary

| Acronym | Term | Notes |
|---------|------|-------|
| AP | Armor Point | Subtracts from damage taken. |
| CHA | Charisma | Attribute. |
| — | Check | Roll 1d6; succeed if below the relevant attribute. |
| CON | Constitution | Attribute. |
| d6 | Six-sided die | The only die needed for attribute checks. Damage and tables may use more than one d6. |
| DEX | Dexterity | Attribute. |
| — | Advantage | Roll 2d6, use the lower die. |
| — | Disadvantage | Roll 2d6, use the higher die. |
| GM | Game Master | |
| HD | Hit Die / Hit Dice | Creature level; also dice rolled for creature HP and often for damage. |
| HP | Hit Point | |
| INT | Intelligence | Attribute. |
| NPC | Non-Player Character | A character used by the GM — for example to set objectives, provide information, or sell equipment. |
| OOA | Out of Action | At 0 HP: unconscious, no actions. |
| PC | Player Character | |
| STR | Strength | Attribute. |
| WIS | Wisdom | Attribute. |
